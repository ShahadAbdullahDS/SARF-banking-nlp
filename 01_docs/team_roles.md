# Team Roles and Handoff Rules

| Role | Owner | Main responsibility |
|------|---|---|
| A    | Project Lead | Research question, data integrity, decisions, audits, and final review. |
| B    | Synthetic Data Owner | Prompts, generation batches, cleaning, and corpus audit. |
| C    | Baselines and Analysis Owner | SVM, TextCNN, metrics, figures, and error analysis. |
| D    | AraBERT Owner | AraBERT runs, CPT, checkpoints, configs, and demo. |

## Handoff rule
Every completed task must include:
- Input file or link.
- Output file or link.
- How to reproduce it.
- Two checks completed.
- Any open issue or blocker.

## Scope rule
Do not add a chatbot, RAG, extra dialects, or new experiments without approval from A.
